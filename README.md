# MobiPhysio-Net

Reproducible implementation and evaluation of **MobiPhysio-Net** — a ViT spatial encoder, a temporal
Transformer encoder and Dynamic-Time-Warping (DTW) distances to a *training-only* reference bank,
fused for 9-class physiotherapy exercise recognition — against five baseline families (SVM, 2D-CNN,
LSTM, CNN-LSTM, ResNet50) on the public **MobiPhysio** dataset
([doi:10.7910/DVN/XSI0QN](https://doi.org/10.7910/DVN/XSI0QN), version 3.0, CC0).

> **Scope.** Task A (exercise recognition) is the primary result. Recognising *which* exercise is
> performed is **not** an assessment of movement correctness and carries no clinical claim. Task B
> (regression of physiotherapists' EAAQ scores) is reported as an exploratory probe.

> **Final comparison scope:** SVM, 2D-CNN, LSTM, CNN-LSTM, ResNet50, MobiPhysio-Net (decision log D4,
> `reports/experiment_decision_log.md`). A BiLSTM baseline was also trained and is reported only in
> `results/supplementary/` and Table S3; it is outside the final scope by a project decision, not for a
> technical reason, and its mean macro F1 (0.798 ± 0.023) is slightly higher than MobiPhysio-Net's.

## What the results do and do not show

* **No superiority claim.** MobiPhysio-Net has the highest mean macro F1 of the six final models and is
  consistently better (every seed, participant-bootstrap CI excluding 0) than SVM, 2D-CNN, CNN-LSTM and
  ResNet50, but not than LSTM (better in 2 of 3 seeds; CI [-0.005, 0.077]). The out-of-scope BiLSTM scored
  slightly higher (0.798 ± 0.023), so this ranking does not extend to every model tested.
* **The DTW branch has no reliable effect.** The seed-42 paired bootstrap favours the full model
  (+0.060), but with seeds 1 and 2 the no-DTW variant is better; the seed-paired mean difference is
  +0.004. The **temporal encoder** is the component that matters (+0.08 to +0.14 at every seed).
* Last-block ViT fine-tuning *under an 8-epoch CPU budget* was worse than the frozen ViT; this reflects the
  budget, not fine-tuning in general.
* From-scratch CNNs at 112 px (2D-CNN, CNN-LSTM) are far behind pre-trained-feature models.
* **Circumduction (E05) → Abduction (E01)** is the largest MobiPhysio-Net error (41 of 96 E05 videos, seed 42)
  and is frequent for SVM, LSTM and ResNet50 too; the lying/floor exercises (E07–E09) are almost never
  confused with the standing ones.
* **Cost:** MobiPhysio-Net needs ~2.3 s per video on one CPU thread, 98% of it the ViT; DTW adds ~35 ms.
  SVM is ~40× faster at lower accuracy and scores highest in 4 of 5 (post-hoc) multi-criteria weightings.
* **Task B is negative:** video-feature regressors do not beat a constant or per-exercise mean for the
  EAAQ score (despite high inter-judge agreement, ICC(2,1) = 0.914).
* Data issue found: two byte-identical published videos carry different participant labels; they are
  excluded (see `docs/DATASET.md`, `experiments/full_v1_superseded/SUPERSEDED.md`).

```
scripts/            setup_environment, run_inventory, run_download, run_all_models, verify_results, make_archive

reports/            audits, decision log, final validation, determinism check, final report
data/manifests/     Dataverse metadata + inventory, video manifest, EAAQ parse, splits, audits
experiments/<exp>/  one directory per run (run_manifest.json, predictions, metrics, history) + registry
results/            aggregated tables, prediction copies, figures, reports, logs, run_manifest.json
docs/               DATASET, MOBIPHYSIO_NET_ALGORITHMS, EXPERIMENT_PROTOCOL, REPRODUCIBILITY, LIMITATIONS
```

Raw videos, decoded frame caches, features and checkpoints live in an external data directory
(`MOBIPHYSIO_DATA_DIR`, default `../mobiphysio_data`) and are **not** part of this repository.

## Quick start

```bash
pip install -r requirements-dev.txt
export PYTHONPATH=src MOBIPHYSIO_DATA_DIR=/data/mobiphysio   # needs ~30 GB free
python -m mobiphysio.cli inventory          # DOI -> metadata + inventory manifests
python -m mobiphysio.cli preprocess         # stream 158.7 GB: download -> MD5 -> 16 frames -> cache -> delete
python -m mobiphysio.cli run-all --skip-preprocess
python -m mobiphysio.cli --experiment pilot run-all --skip-preprocess   # reduced pilot, kept separate
python -m pytest -q
```

Every command has `--help`; configuration overrides use `--set <model>.<key>=<value>`.

## Method in one paragraph

16 uniformly spaced, letterboxed 224×224 RGB frames per video → frozen ViT-S/16 CLS features → 2-layer
temporal Transformer with padding masks → masked mean `g`. In parallel, path-normalised constrained DTW
(Sakoe-Chiba band 4) between the encoded sequence and 27 reference videos (3 DTW k-medoids per class,
selected from training videos only), aggregated per class by `min`, standardised with training-only
statistics → `q ∈ R⁹`. `[g ‖ q]` → MLP → softmax. DTW is a no-gradient feature branch; gradients update
the temporal encoder and head (and the last ViT block in the fine-tuning ablation). Details:
[docs/MOBIPHYSIO_NET_ALGORITHMS.md](docs/MOBIPHYSIO_NET_ALGORITHMS.md).
